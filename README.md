# Sistema de Gerenciamento Escolar  

O **Sistema de Gerenciamento Escolar** é uma aplicação desktop desenvolvida **100% em Java**, sem o uso de frameworks externos. Projetado para a cadeira de POO  

## 🏫 Principais Funcionalidades  
- ✅ **Cadastro e Gerenciamento de Alunos e Professores** – Permite registrar e gerenciar informações como nome, matrícula e contato.  
- ✅ **Interface Gráfica Simples e Funcional** – Desenvolvida com **Java Swing**.  
- ✅ **Persistência de Dados** – Armazena as informações banco de dados via **JDBC**.  

## 🛠 Tecnologias Utilizadas  
- 🔹 **Java** – Linguagem de programação  
- 🔹 **Java Swing** – Construção da interface gráfica  
- 🔹 **JDBC** – Comunicação com banco de dados
- 🔹 **Banco de Dados** *MySQL*
